## Как внести исправление

Откройте папку проекта в VS Code или другом редакторе. Подвопрос **1.4.2** соответствует файлу `sections/01_oscillations/q04/s02.tex`. Соседний `q04/main.tex` содержит формулировку общего вопроса, блоки повторения и источники. Список вопросов и нумерацию обновляет LaTeX при сборке.

Небольшие исправления можно сразу предложить через Pull Request. Для содержательной правки укажите номер подвопроса, суть изменения и источник либо воспроизводимый вывод. Если удобнее сначала обсудить проблему, создайте Issue с номером вопроса и описанием замечания. Отметки принятия выставляет соответствующий рецензент.

Локальная компиляция для редактирования необязательна: [GitHub Actions](.github/workflows/latex.yml) настроен на сборку и техническую проверку Pull Requests и изменений ветки `main`. Промежуточные PDF для проверки правок доступны в артефактах успешного запуска. Готовая редакция для читателей — [radiophysics.pdf](radiophysics.pdf) в корне проекта.

## Сборка из исходников

Этот раздел нужен, если вы хотите самостоятельно собрать PDF после изменения исходников.

<details>
<summary>Показать инструкцию по сборке</summary>

Нужен TeX-дистрибутив с **XeLaTeX, BibTeX и latexmk**, русскими переносами и пакетами из [преамбулы](config/preamble.tex), включая TikZ/circuitikz. Шрифты включены в проект.

Из корня проекта:

```sh
latexmk -xelatex main.tex
```

Результат — **`build/main.pdf`**. Повторные проходы для библиографии, списка вопросов и ссылок выполняет latexmk.

В VS Code с расширением LaTeX Workshop предусмотрен рецепт **latexmk (XeLaTeX)** в общей конфигурации проекта. **Python для обычной сборки не требуется.** Готовые рисунки лежат в `figures/`; их пересчёт не входит в стандартную сборку.

</details>
